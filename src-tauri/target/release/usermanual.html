1. 软件界面概览

软件界面由以下主要区域组成：

区域位置功能
菜单栏顶部文件、编辑、视图、设置、帮助等菜单
工具箱左侧选择工具、设备创建、连线创建等
画布中央模型编辑区域
属性面板右侧显示和编辑选中对象的属性
状态栏底部显示当前状态信息

2. 菜单栏操作

2.1 文件菜单

新建画布

  1. 点击菜单栏 「文件」
  2. 选择 「新建」
  3. 如当前画布有内容，系统会询问是否保存
  4. 选择保存或不保存后，画布将被清空

打开文件

  1. 点击菜单栏 「文件」
  2. 选择 「打开」
  3. 在弹出的文件选择对话框中，选择 .json 格式的布局文件
  4. 点击「打开」按钮

保存文件

  1. 点击菜单栏 「文件」
  2. 选择 「保存」 或 「另存为」
  3. 选择保存位置并输入文件名
  4. 点击「保存」按钮

导出图片

  1. 点击菜单栏 「文件」
  2. 选择 「导出图片」
  3. 选择保存位置并输入文件名
  4. 图片将以 PNG 格式保存

2.2 编辑菜单

删除选中对象

  1. 选中要删除的设备或连线
  2. 点击菜单栏 「编辑」
  3. 选择 「删除」
  4. 或直接按 Delete 键

清空画布

  1. 点击菜单栏 「编辑」
  2. 选择 「清空画布」
  3. 确认清空操作

2.3 视图菜单

缩放操作

  1. 点击菜单栏 「视图」
  2. 选择 「放大」 或 「缩小」
  3. 或使用鼠标滚轮进行缩放

重置视图

  1. 点击菜单栏 「视图」
  2. 选择 「重置视图」
  3. 画布将恢复到初始缩放和位置

2.4 设置菜单

画布设置

  1. 点击菜单栏 「设置」
  2. 选择 「画布设置」
  3. 在弹出的对话框中设置：
    • 画布宽度（毫米）
    • 画布高度（毫米）
  4. 点击「确定」保存设置

产品管理

  1. 点击菜单栏 「设置」
  2. 选择 「产品管理」
  3. 在弹出的对话框中进行产品配置

物料管理

  1. 点击菜单栏 「设置」
  2. 选择 「物料管理」
  3. 在弹出的对话框中进行物料配置

工具管理

  1. 点击菜单栏 「设置」
  2. 选择 「工具管理」
  3. 在弹出的对话框中进行工具配置

工具配置说明：

  • 工具编码：工具的唯一标识符
  • 工具名称：工具的显示名称

工具管理操作：

  • 点击 「新建工具」 创建新工具
  • 点击 「编辑」 修改已有工具
  • 点击 「删除」 删除工具
注意：工具的安装时间需要在加工站的产品配置中单独设置，因为同一工具在不同产品加工时可能需要不同的安装时间。

3. 工具箱使用

  3. 每个模型至少需要一个起点

终点

图标：紫色菱形

  2. 在画布上点击创建终点
  3. 每个模型至少需要一个终点

3.4 连线创建工具

点击连线图标展开连线类型选择：

类型说明
直线两点之间直接连接
肘形连线自动生成带拐点的折线，可拖动控制点调整拐点位置

创建连线：

3.7 车间

图标：带虚线分隔的矩形

  1. 点击车间图标

  3. 可将设备、仓库、缓冲区放在车间内，移动车间时会同时移动车间内的设备

7.3 设备 (Station)

创建步骤：

  1. 在工具箱点击矩形或圆形图标
  2. 在画布上点击创建

属性配置：

标签属性说明
基础信息名称设备显示名称
基础信息宽度/高度设备尺寸（毫米）
产品设置允许产品选择可加工的产品
加工设置加工时间加工一个产品所需时间（秒）

设置加工产品：

  1. 切换到「产品设置」标签
  2. 勾选允许加工的产品
  3. 如果不勾选任何产品，则表示可加工所有产品

设置加工时间：

  1. 切换到「加工设置」标签
  2. 选择「进料规则」，"即来即产"表示产品生成后立即加工；"集齐后加工"用于有多个上游设备的情况，只有当所有上游设备加工的产品都到达最少一个时才会开始加工
  3. 「分布类型」的选择影响设备加工时间的随机生成方法，可选择"正态分布"、"均匀分布"、"指数分布"、"三角分布"，然后根据出现的属性填写时间参数。如"正态分布"只填写平均值的话，则会默认使用标准差为 0 的正态分布。

设置产品加工时间：

  1. 在「加工设置」标签中，可以为不同产品设置不同的加工时间
  2. 点击「添加产品加工时间」按钮
  3. 选择要设置的产品
  4. 为该产品设置专门的加工时间和分布类型
  5. 如果某个产品没有专门设置，则使用默认的加工时间
  6. 可以添加多个产品的加工时间配置

产品加工时间优先级：

  • 如果为某个产品专门设置了加工时间，则使用该设置
  • 如果没有专门设置，则使用默认的加工时间
  • 这样可以灵活地为不同产品设置不同的加工时长

设置产品加工工具：

  1. 在「加工设置」标签中，展开产品配置
  2. 在「加工工具」区域，勾选该产品需要的工具
  3. 对于已选中的工具，可以设置该工具的安装时间（秒）
  4. 安装时间同时也是卸载时间
  5. 每个产品可选择多个工具，每个工具可单独设置安装时间

工具切换时间计算规则：

  • 首次加工：如果是工作站的第一次加工，需要安装所有需要的工具，切换时间 = 所有工具安装时间之和
  • 相同产品：如果本次加工的产品与上次相同，无需切换工具，切换时间 = 0
  • 不同产品：如果本次加工的产品与上次不同，需要计算工具切换时间：
    • 卸载不再使用的工具（卸载时间 = 安装时间）
    • 安装新需要的工具
    • 切换时间 = 卸载工具时间 + 安装工具时间
  • 示例：上次使用工具A(10s)、B(15s)，本次使用工具B(15s)、C(20s)
    • 需要卸载：工具A(10s)
    • 需要安装：工具C(20s)
    • 切换时间 = 10s + 20s = 30s（工具B已安装，无需切换）

甘特图中的工具切换显示：

  • 工具切换时间在甘特图中以橙色色块显示
  • 加工任务以产品颜色显示
  • 鼠标悬停可查看详细信息

7.6 缓冲区 (Buffer)

标签属性说明

缓冲区设置容量最大存储数量

缓冲区使用规则：

缓冲区用于平衡上下游工序的生产节拍，当上游生产速度快于下游时，缓冲区暂存产品，避免上游阻塞；当下游需要产品时，缓冲区按先进先出原则释放产品。

典型使用场景：

  • 上游加工站生产速度快于下游，需要暂存产品
  • 多个上游加工站共用一个下游加工站，需要缓冲区汇聚产品
  • 需要控制投料节奏，防止在制品过多

缓冲区控制逻辑：

  1. 入站运输（上游产品进入缓冲区）：
    • 缓冲区达到最大容量时不再接收新产品
    • 收集所有直接连接到缓冲区的上游加工站中等待运输的产品
    • 按到达时间FIFO排序，优先运输最早到达的产品
    • 遍历所有上游加工站，每个站运输排序后的第一个等待运输产品
    • 每运入一个产品，缓冲区当前库存加1，达到容量上限则停止
  2. 出站释放（缓冲区产品送往下游）：
    • 仅当下游设备（加工站、装配站、终点）的有效在制品数（WIP + 在途 + 加工中）≤ 2 时，才允许释放产品
    • 按产品进入缓冲区的先后顺序，优先释放最早进入的产品
    • 按基础规则（产品匹配 → 优先空闲 → 距离最近）选择下游目标设备
    • 出站释放成功后，会立即检查缓冲区容量并尝试从上游继续运入产品
  3. 容量管控（投料控制）：
    • 潜在库存 = 缓冲区当前库存 + 所有上游加工站的等待运输产品数之和
    • 当潜在库存 ≥ 缓冲区最大容量时，上游路径对应的所有起点暂停投料
    • 当潜在库存 < 缓冲区最大容量时，恢复已暂停起点的投料
    • 系统沿缓冲区的上游路径回溯，找到所有直接或间接向缓冲区供货的起点节点

7.8 装配站 (AssemblyStation)

创建步骤：

  1. 在工具箱点击装配站图标

功能说明：

装配站用于将多个上游设备的产品组装成一个产品。它接收来自多个上游节点的产品，当所需的上游产品都到达后，进行组装加工，产出最终产品。

属性配置：

标签属性说明
基础信息名称设备显示名称
产品设置允许产品选择可装配的产品
加工设置加工时间装配一个产品所需时间（秒）

设置装配产品：

  1. 切换到「产品设置」标签
  2. 勾选允许装配的产品
  3. 每个产品可以设置独立的上游来料需求

设置上游来料需求：

  1. 在「产品设置」标签中，展开已选产品的配置
  2. 在「上游来料需求」区域，可以看到所有连接到装配站的上游节点
  3. 为每个上游节点设置装配一个产品所需的来料数量
  4. 重要：所有上游节点的需求量必须大于0，否则检查时会报错

装配逻辑说明：

  • 装配站会等待所有上游节点的产品到达
  • 当每个上游节点的产品数量都达到设定的需求量时，才开始装配
  • 装配完成后，产出一个产品送往下游
  • 例如：产品A需要上游节点1的2件产品和上游节点2的3件产品，则只有当节点1有2件、节点2有3件产品时，才会开始装配

检查要求：

在模拟前检查时，装配站需要满足以下条件：

  1. 必须选择至少一个可装配的产品
  2. 对于每个已选产品，必须设置上游来料需求
  3. 每个上游节点的需求量必须大于0
  4. 如果检查不通过，将显示错误信息，无法开始模拟

加工时间设置：

与普通工作站相同，装配站支持：

  • 为不同产品设置不同的加工时间
  • 选择分布类型（正态分布、均匀分布、指数分布、三角分布）
  • 设置工具及安装时间

8. 连线创建与配置

8.1 创建连线

  1. 在工具箱选择连线类型
  2. 将鼠标移到源设备边缘的锚点上（设备边缘的小圆点）点击一下
  3. 鼠标移动到目标设备的锚点，再点击一下，完成连线
  4. 连线既代表了节点之间的关联关系，也标明了上下游关系，同时也是节点之间的运输路线（起点到下游，节点到终点的连线除外），连线的长度就是运输路线长度

8.4 运输模式说明

连续运输：

  • 传送带式的运输
  • 适合流水线生产
  • 可设置同时传送带能够承载的产品数，默认为不限数量

离散运输：

  • 小车批量运输
  • 需设置小车数量和单次运量
  • 运输记录包含批次信息

9. 模拟运行

9.1 打开模拟控制面板

  1. 模拟控制面板默认打开，在界面底部
  2. 可点击菜单栏 「模拟」
  3. 选择 「隐藏/显示模拟控制面板」，控制是否显示模拟控制面板

9.2 设置模拟参数

模拟时长：

  1. 点击「设置」按钮，打开下方设置面板
  2. 在「模拟时长」输入框输入秒数
  3. 或使用增减按钮调整
  4. 默认为 3600 秒（1小时）

模拟速度：

  1. 拖动速度滑块
  2. 可选范围：1x ~ 100x
  3. 常用速度：1x、2x、5x、10x、50x、100x

动态平衡算法：

  1. 选择算法类型：
    • 无：使用基础规则
    • 动态平衡算法(在制品)：根据在制品数量选择路线
    • 动态平衡算法(设备利用率)：根据设备利用率选择路线

模拟模式：

  1. 点击「模拟模式」下拉菜单选择模拟结束条件：
    • 固定时长：按照设定的模拟时长运行，模拟到达设定时长后结束（默认模式）
    • 固定产量：按照设定的目标产量运行，当所有起点达到目标产量且所有产品到达终点后结束
  2. 选择「固定产量」模式时，需要在起点的属性中设置目标产量

9.3 运行模拟

获取工艺路线：

  1. 点击 「获取工艺路线」 按钮
  2. 获取模型中所有产品的工艺路线，所有选择的产品最少应有一条完整的工艺路线
  3. 可点击 「查看工艺路线」 按钮，查看工艺路线

开始模拟：

  1. 点击 「开始」 按钮
  2. 模拟开始运行
  3. 状态显示为「运行中」

暂停模拟：

  1. 模拟运行中点击 「暂停」 按钮
  2. 模拟暂停
  3. 状态显示为「已暂停」

继续模拟：

  1. 暂停状态下点击 「继续」 按钮
  2. 模拟继续运行

重置模拟：

  1. 点击 「重置」 按钮
  2. 模拟状态清零
  3. 所有设备恢复初始状态

附录：常见问题

Q1: 如何创建一个完整的生产线模型？

  1. 创建起点，设置产品和生成间隔
  2. 创建工作站，设置加工时间和允许产品
  3. 用连线连接起点到工作站
  4. 继续添加工作站和连线
  5. 创建终点，连接到最后的工作站
  6. 在产品管理中设置工艺路线

Q2: 模拟没有产品产出怎么办？

检查以下设置：

  1. 起点是否设置了产品
  2. 工作站是否允许加工该产品
  3. 连线是否正确连接
  4. 产品工艺路线是否配置

Q3: 如何实现产品分流？

  1. 从一个设备创建多条连线到不同设备
  2. 在模拟设置中选择动态平衡算法
  3. 系统会根据算法自动分配产品

Q4: 仓库容量不足怎么办？

  1. 选中仓库
  2. 在属性面板增加容量值
