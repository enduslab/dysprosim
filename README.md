# DysProSim - 离散生产与物流系统模拟工具

**版本：** v1.0.0

## 软件简介

DysProSim 是一款专业的离散生产与物流系统模拟工具，用于设计、模拟和分析离散制造环境下的生产流程与物流系统。通过可视化的建模界面，用户可以快速构建生产系统模型，模拟产品在各工序间的流动，分析生产瓶颈，优化资源配置，提升整体生产效率。

## 主要功能

### 1. 可视化建模

- **拖拽式设计**：通过工具箱拖拽设备节点到画布，快速构建生产系统模型
- **连线编辑**：通过连线建立设备之间的物料流转关系
- **多选操作**：支持框选多个节点，批量移动、删除
- **画布缩放**：支持鼠标滚轮缩放画布，便于查看大型模型

### 2. 设备类型

| 设备类型 | 说明 |
|---------|------|
| **起点 (StartNode)** | 产品进入系统的入口，可设置产品生成间隔和初始数量 |
| **终点 (EndNode)** | 产品完成加工离开系统的出口 |
| **工作站 (Station)** | 基本加工设备，可设置加工时间、允许产品等属性 |
| **装配站 (AssemblyStation)** | 将多个上游设备的产品组装成一个产品，支持上游来料需求配置 |
| **车间 (Workshop)** | 多工位加工设备，支持并行加工多个产品 |
| **缓冲区 (Buffer)** | 临时存储区域，用于平衡上下游工序的生产节拍，支持容量管控和投料控制 |
| **仓库 (Warehouse)** | 具有固定容量的存储设施，可存储多种产品 |

### 3. 产品与物料管理

- **产品定义**：定义产品编码、名称、颜色标识
- **工艺路线**：设置产品的加工路线，指定经过的设备顺序
- **物料清单 (BOM)**：定义每种产品的原料消耗，支持多种原料和用量设置

### 4. 运输模式

- **连续运输**：产品逐个运输，适合流水线生产
- **离散运输**：支持小车批量运输，可设置：
  - 小车数量
  - 单次最大运量
  - 运输时间

### 5. 模拟控制

- **模拟速度调节**：支持 1x、2x、5x、10x、50x、100x 倍速
- **暂停/继续**：随时暂停模拟，观察系统状态
- **单步执行**：逐步执行模拟，便于调试分析

#### 模拟模式

系统支持两种模拟模式：

| 模式 | 说明 |
|------|------|
| **固定时长模式** | 模拟运行指定时长后自动结束，适用于产能分析、瓶颈识别等场景 |
| **固定产量模式** | 当所有设定的目标产量达成后自动结束，适用于生产计划验证、交期评估等场景 |

#### 固定产量模式配置

在固定产量模式下，需要在终点节点设置各产品的目标产量：

1. 选中终点节点，在属性面板中切换到"目标产量"标签页
2. 系统会自动列出该终点上游可达的所有产品
3. 勾选需要控制产量的产品，并设置目标产量值
4. 未勾选的产品不参与结束判断

**工作原理（源头控制法）：**

- 当某产品在终点达到目标产量时，系统立即停止该产品对应起点的投料
- 当所有勾选的产品都达到目标产量时，模拟立即结束
- 管道中残留的在制品不会影响模拟结束判断
- 支持多产品独立控制：不同产品可以有不同的目标产量，各产品独立达标、独立停止投料

**注意事项：**

- 固定产量模式下，模拟前检查会验证每条完整工艺路线的终点是否设置了对应产品的目标产量
- 如果一个起点生产的产品没有在任何终点设置目标产量，将无法开始模拟
- 装配站产出的产品达标时，会自动停止所有参与装配的上游起点投料

### 6. 动态平衡算法

系统提供两种智能路由选择算法：

#### 动态平衡算法(在制品)
根据各条路线的当前在制品总量，选择负载最轻的路线，实现生产线的负载均衡。

#### 动态平衡算法(设备利用率)
根据各条路线的最高设备利用率，选择瓶颈设备负载较低的路线，避免过度集中。

### 7. 统计分析

模拟完成后提供丰富的统计分析功能：

- **完成产品统计**：按产品种类统计最终完成加工的产品数量
- **原料消耗统计**：统计各类原料的总消耗量
- **设备利用率**：计算各设备的利用率百分比
- **设备加工统计**：统计各设备加工各产品的数量
- **设备最大在制品**：记录各设备在模拟过程中的最大在制品数
- **设备等待数统计**：记录各设备的最大等待加工数和最大等待运输数
- **仓库利用率**：统计各仓库的最大利用率
- **路径利用率**：统计各连线路径的利用率
- **甘特图**：以时间线形式展示各设备的加工情况

### 8. 图表展示

统计结果以直观的图表形式展示：

- 柱状图：完成产品数、原料消耗、设备利用率、设备加工数量、设备最大在制品、路径利用率
- 仓库利用率柱状图：根据利用率百分比自动着色（红色>90%、橙色>70%、蓝色>50%、绿色<50%）

### 9. 数据导出

- **导出PDF**：将模拟记录的完整统计信息导出为PDF文件，包含图表和统计数据
- **导出Excel**：将模拟记录的详细数据导出为Excel文件，便于进一步分析

### 10. 缓冲区控制逻辑

缓冲区是平衡上下游工序生产节拍的关键设备，其控制逻辑包括：

**入站运输：**
- 缓冲区达到最大容量时不再接收新产品
- 收集所有上游加工站中等待运输的产品，按到达时间FIFO排序
- 遍历所有上游加工站，每个站运输排序后的第一个等待运输产品
- 每运入一个产品，缓冲区当前库存加1，达到容量上限则停止

**出站释放：**
- 仅当下游设备（加工站、装配站、终点）的有效在制品数（WIP + 在途 + 加工中）≤ 2 时，才允许释放产品
- 按产品进入缓冲区的先后顺序，优先释放最早进入的产品
- 出站释放成功后，会立即检查缓冲区容量并尝试从上游继续运入产品

**容量管控（投料控制）：**
- 潜在库存 = 缓冲区当前库存 + 所有上游加工站的等待运输产品数之和
- 当潜在库存 ≥ 缓冲区最大容量时，上游路径对应的所有起点暂停投料
- 当潜在库存 < 缓冲区最大容量时，恢复已暂停起点的投料

## 系统要求

- **操作系统**：Windows 10/11 (64位)
- **运行环境**：无需额外依赖，安装包自动处理 WebView2 运行时

## 安装说明

1. 下载安装包 `DysProSim_1.0.0_x64-setup.exe`
2. 双击运行安装程序
3. 选择安装语言（简体中文/English）
4. 按照安装向导完成安装
5. 桌面将自动创建快捷方式

## 快速开始

1. **创建设备**：从左侧工具箱拖拽设备到画布
2. **连接设备**：点击设备锚点并拖动到目标设备建立连线
3. **设置产品**：在菜单栏选择"产品管理"，定义产品和工艺路线
4. **配置参数**：选中设备后在右侧属性面板设置加工时间等参数
5. **开始模拟**：点击菜单栏"模拟控制"按钮，设置参数后开始模拟
6. **查看结果**：模拟结束后点击"模拟记录"查看统计分析
